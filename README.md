- .NET 8 REST API
- Angular
- PostgreSQL 17
- EF Core 8
- Quartz
- xUnit
- GitHub / code review
- Linux deployment
- CI/CD

## Repository structure

- `src` — backend projects
- `tests` — automated tests
- `frontend` — Angular application
- `docs` — architecture, UML, decisions
- `.github/workflows` — CI/CD
