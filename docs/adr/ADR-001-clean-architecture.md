# ADR-001

## Title

Use Clean Architecture

## Status

Accepted

## Context

Проект будет развиваться постепенно.
Необходимо минимизировать связанность между слоями.

## Decision

Использовать Clean Architecture.

## Consequences

### Плюсы

- независимость доменной модели;
- высокая тестируемость;
- инфраструктуру можно заменить с минимальными изменениями;
- бизнес-логика не зависит от ASP.NET Core и EF Core.

### Минусы

- больше проектов в Solution;
- выше порог входа;
- больше абстракций.
