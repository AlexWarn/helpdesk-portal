## Что нового понял

- User — это не таблица.
- Entity определяется идентичностью.
- Email не является идентификатором пользователя.
- Password относится к аутентификации.
- Domain Model строится вокруг поведения.

## Что было неожиданным

Пароль, возможно, вообще не должен быть частью User.
